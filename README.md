# Thai Todo (Vite + React + Tailwind)

แอปรายการงานภาษาไทย — React 18, Vite 5, Tailwind CSS 3, lucide-react

## เริ่มใช้งาน

```bash
npm install
npm run dev      # เปิด http://localhost:5173
npm run build    # สร้างไฟล์ production ในโฟลเดอร์ dist
npm run preview  # ดูผล build
```

ข้อมูลเก็บใน React state เท่านั้น (ไม่ใช้ localStorage) รีเฟรชแล้วจะรีเซ็ต
